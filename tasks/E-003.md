  - summary: Add an isolated generator/evaluator execution loop so quality checks are independent from implementation context.
  - description: |
      ## Product Context
      Evaluation done in the same context as generation can miss defects and overfit to local assumptions.

      ## User Story
      As a maintainer, I want evaluator runs to use fresh context so pass/fail decisions reflect true quality and acceptance criteria.

      ## Acceptance
      - [ ] Generator and evaluator handoff contract is explicit.
      - [ ] Evaluator runs in isolated context by default.
      - [ ] Parallel evaluation is optional and capability-based.
      - [ ] Verdicts map deterministically to status transitions.

      ## Steps
      - [ ] define required handoff artifacts.
      - [ ] implement isolated evaluator mode.
      - [ ] add optional parallel mode.
      - [ ] codify verdicts and transition policy.
